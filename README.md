# ESA Danse — Gala 2027

Code source du site « Coulisses · Organisation du gala ».

Site actuel : https://gala-esa-justine.ovalmanta1.chatgpt.site/

Ce dépôt contient les fichiers du site. Les données enregistrées dans la base du site ne sont pas incluses. Le site utilise actuellement l'hébergement Sites, une base Cloudflare D1 et l'authentification ChatGPT. Le déposer sur GitHub ne le publie pas sur GitHub Pages et ne synchronise pas automatiquement les modifications avec le site actuel.

L'accès partagé aux tâches est configuré sur le site : consultation publique et modification réservée aux deux comptes autorisés après connexion ChatGPT. Les changements sont partagés et actualisés toutes les 15 secondes hors formulaire ouvert. Les données des bénévoles restent réservées aux coordinatrices. La publication automatique depuis GitHub n'est pas configurée.

La documentation technique se trouve dans `DEVELOPMENT.md`.
